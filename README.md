# IBM Data Science – Curso de Ciencia de Datos

## Descripción del proyecto

Este repositorio forma parte de las actividades prácticas del curso de Ciencia de Datos de IBM. Su objetivo es aplicar y fortalecer los conocimientos adquiridos en el análisis de datos, la programación y el uso de herramientas tecnológicas para resolver problemas mediante el manejo de información.

## Objetivos de aprendizaje

- Familiarizarse con GitHub y la gestión de repositorios.
- Desarrollar habilidades básicas de programación para la ciencia de datos.
- Aprender a organizar, documentar y compartir proyectos.
- Aplicar herramientas y técnicas de análisis de datos.

## Herramientas utilizadas

- GitHub para alojar y administrar el repositorio.
- Python para programación y análisis de datos.
- Jupyter Notebook para desarrollar y documentar ejercicios prácticos.
